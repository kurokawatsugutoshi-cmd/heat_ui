## 1. 目的

管理者のログインと、作業者がどの現場の誰として動いているかを定義する。

## 2. 適用範囲

定義すること: 管理者の認証、作業者がパスワードを持たないこと、現場トークン、作業者セッションに載せるもの。

定義しないこと: 体調の値（D07、D08）、個人トークンの中身（D11）、画面の部品（D06 の A-01、W-01、W-03）。

## 3. 参照

- D03
- `spec-heatstroke-app.pdf` の QR 起動

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| 現場トークン | 出社用または休憩用QRに入る秘密。現場とフォーム種別を決める |
| 作業者セッション | ブラウザが短時間だけ持つ、現場と本人の表示 |

## 5. 要求

| ID | 要求 | 状態 |
| --- | --- | --- |
| D10-R01 | 管理者はログインIDとパスワードで入り、自己登録はしない。発行は本部が行う | 確定 |
| D10-R02 | 管理者の操作範囲は D03 に従う | 確定 |
| D10-R03 | 作業者にパスワード画面を出さない | 確定 |

| D10-R06 | 作業者セッションは長期保存に置かない | 確定 |
| D10-R07 | 管理者の無操作での切断、失敗時のロック、作業者セッションの分数、SSO の有無は未決とする | 未決 |

## 6. 仕様

### 6.1 管理者（D10-R01、D10-R02、D10-R07）

画面は A-01。ログインの成功と失敗は監査する（書く項目の集合は D14）。

仮の置き値（本番値ではない）: 無操作60分で切断。15分に10回失敗で30分停止。SSO は未決が指定するまで付けない。

### 6.2 作業者（D10-R03〜R06）

| 方式 | セッションに載るもの | 中身の定義 |
| --- | --- | --- |
| 現場QRと属性入力 | 現場、フォーム種別、会社、氏名 | この文書 |
| 個人QR | 上記に作業者ID | トークンの中身は D11。載せ方はこの文書 |

手入力の氏名は他人になり得る。その残りは残し、抑止の強化は D11 である。

セッションが消える条件の仮: 業務日の終わり、最終操作から30分、「終了」のいずれか早い方（Q.10.01）。個人のスマホだけ氏名を残すかは Q.10.02。

## 7. 他領域との受け渡し

ロール（D03）を受け取る。個人トークンの検証結果（D11）をセッションに載せる。画面の終了操作（D06 の W-10）がセッションを消す。
