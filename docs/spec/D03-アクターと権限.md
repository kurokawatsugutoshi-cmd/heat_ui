## 1. 目的

誰が、どの範囲の記録と操作を行えるかを定義する。

## 2. 適用範囲

定義すること: ロールと操作範囲。

定義しないこと: ログインのやり方（D10）、画面の部品（D06）、所属データの持ち方（D14）。

## 3. 参照

- `report-0924.pdf` の残課題（本部 / 現場所長 / 協力会社・職長）
- D02

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| worker | 現場で自分の体調を送る人 |
| foreman | 協力会社の職長。自社の範囲を見る |
| site_manager | 現場所長。自現場を管理する |
| hq | 本部管理者。全現場を横断する |

## 5. 要求

| ID | 要求 | 状態 |
| --- | --- | --- |
| D03-R01 | 作業者は自分の送信と、周知・お知らせの閲覧だけを行い、他者のバイタルを見ない | 確定 |
| D03-R02 | 職長は、担当現場かつ自社の回答と、自社分のアラートを扱う | 確定 |
| D03-R03 | 現場所長は、自現場の回答、アラート、緊急電話、QRを扱う | 確定 |
| D03-R04 | 本部は、全現場の閲覧、アカウント、設問、閾値、お知らせ、抽出を扱う | 確定 |
| D03-R05 | 作業者と管理者は同じログイン画面を使わない | 確定 |
| D03-R06 | 職長が抽出できるかは未決とする | 未決 |
| D03-R07 | 現場所長が複数現場を兼ねるかは未決とする | 未決 |

## 6. 仕様

操作とロールの対応。丸は可、線は不可、疑問IDは未決。

| 操作 | worker | foreman | site_manager | hq |
| --- | --- | --- | --- | --- |
| 体調の送信 | 可 | 不可 | 不可 | 不可 |
| 回答の閲覧 | 不可 | 自社 | 自現場 | 全現場 |
| アラートの受信 | 不可 | 自社 | 自現場 | 設定した範囲 |
| 現場QR・緊急電話の編集 | 不可 | 不可 | 自現場 | 可 |
| 設問・閾値・アカウント | 不可 | 不可 | 不可 | 可 |
| 抽出 | 不可 | Q.03.01 | 自現場 | 全現場 |

回答の取得範囲は次のとおり（D03-R02 から D03-R04）。

| ロール | 範囲 |
| --- | --- |
| hq | 全件 |
| site_manager | 担当現場 |
| foreman | 担当現場かつ自社 |

## 7. 他領域との受け渡し

ロールコードを D10、D14、D15 へ渡す。画面上のメニューの出し分けは D06 が、この表を参照して行う。
