## 1. 目的

設問の答えを、どの型のどの欄に、どの字面で持つかを定義する。

## 2. 適用範囲

定義すること: 値種別、スロット、単位、受理する字面、受理範囲、回答行の形、同じ人の束ね方。

定義しないこと: 設問の文言と極性（D07）、画面のキーパッド（D06）、閾値との比較（D09）、会社名と氏名の列（D14）。

## 3. 参照

- D07 の設問一覧
- `report-0924.pdf` の集計列（血圧、脈拍、睡眠、はい／いいえ）

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| VK-INT | 整数の測定値。単位は値と一緒に保存しない |
| VK-CODE | 排他の区分。連続量の数値ではない |
| VK-YN | `yes` または `no`。数値の 1 は「はい」であり危険度ではない |
| スロット | `value_int`、`value_code`、`value_yn` のいずれか1つ |

## 5. 要求

| ID | 要求 | 状態 |
| --- | --- | --- |
| D08-R01 | 1設問の値種別は1つである | 確定 |
| D08-R02 | 1つの回答行で埋まるスロットは1つであり、設問の値種別と一致する | 確定 |
| D08-R03 | 判定レベルは値のスロットに入れない | 確定 |
| D08-R04 | 睡眠の区分を、時間の整数として持たない | 確定 |
| D08-R05 | はい／いいえを、血圧と同じ整数列に入れない | 確定 |
| D08-R06 | 休憩時の回答に測定値の設問行を作らない | 確定 |
| D08-R07 | 出社時の回答に休憩専用の設問行を作らない | 確定 |
| D08-R08 | 周知 `C-*` の行を作らない | 確定 |
| D08-R09 | 小数、空、範囲外は保存しない | 確定 |
| D08-R10 | 整数の受理範囲の数値は仮であり、未決が閉じるまで本番値にしない | 仮 |

## 6. 仕様

### 6.1 値種別（D08-R01〜R05）

| value_kind | 埋めるスロット | 埋めないスロット |
| --- | --- | --- |
| VK-INT | value_int | value_code、value_yn |
| VK-CODE | value_code | value_int、value_yn |
| VK-YN | value_yn | value_int、value_code |

### 6.2 設問ごとの受理（D08-R09、D08-R10）

| code | 種別 | 単位 | 受理する字面 | 範囲 |
| --- | --- | --- | --- | --- |
| Q-SYS | VK-INT | mmHg | 整数 | 70〜250（仮。Q.08.01） |
| Q-DIA | VK-INT | mmHg | 整数。Q-SYS より小さい | 40〜150（仮） |
| Q-HR | VK-INT | bpm | 整数 | 30〜200（仮） |
| Q-SLEEP | VK-CODE | なし | ge7、h6、h5。lt5 は Q.07.02 が可のときだけ | 一覧外は拒否 |
| はい／いいえの各 code | VK-YN | なし | yes または no | 未選択は拒否 |

最高血圧が最低血圧以下のときも保存しない。

### 6.3 行（D08-R02、D08-R06〜R08）

回答ヘッダ1件（D14）に、設問値を0件以上ぶら下げる。

| 項目 | 内容 |
| --- | --- |
| response_id | 回答ヘッダ |
| question_code | D07 の code |
| value_int | 整数、または空 |
| value_code | 区分コード、または空 |
| value_yn | yes / no、または空 |

伝送でもキーを分ける。1つの `value` に整数と yes を混ぜない。

```json
{ "code": "Q-SYS", "valueInt": 120 }
{ "code": "Q-SLEEP", "valueCode": "ge7" }
{ "code": "Q-JOB-01", "valueYn": "yes" }
```

会社名と氏名はこの配列に入れない。

### 6.4 同じ人の束ね

| フォーム | 持ち方 | 状態 |
| --- | --- | --- |
| arrival | 同一現場・同一業務日・同一作業者で1件。作業者IDが無いときは現場＋会社名＋氏名＋業務日で仮に同一視する | 仮（Q.08.02、Q.08.03） |
| break | 同日に複数。同一作業者・同一現場で60秒以内の同一値は1件に吸収する | 仮 |

上書きする場合、旧スロットは監査に残す。作業者は他人の値を変更できない。氏名は送信時点の文字列をヘッダに写し、後のマスタ改名で過去を書き換えない。

## 7. 他領域との受け渡し

受け取るもの: 設問コードと form_type（D07）。

渡すもの: 受理されたスロット。D09 は受理後の値だけを読む。D15 は伝送の形をこの節に合わせる。

## 8. 未決事項

| ID | 問い | 理由 |
| --- | --- | --- |
| Q.08.01 | 整数として受理する範囲 | 70〜250 等は入力ミスを弾く仮であり、資料に無い |
| Q.08.02 | 同姓同名の手入力を別人の2件にするか | 作業者IDが無いときの同一視が仮 |
| Q.08.03 | 出社時の再送は上書きか追記か | 上書きは仮 |
