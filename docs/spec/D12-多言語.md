## 1. 目的

画面と設問を、ブラウザの自動翻訳に頼らず切り替えることを定義する。

## 2. 適用範囲

定義すること: 言語コード、訳の置き場所、翻訳しないもの、訳が欠けたときの扱い。

定義しないこと: 設問の意味（D07）、お知らせの配信条件（D13）、画面の切り替え部品の位置（D06 のヘッダ）。

## 3. 参照

- `report-0924.pdf` のブラウザ翻訳（240言語）と、インドネシア語の実例
- D02 の対象外（240言語の同時提供、ブラウザ翻訳への誘導）

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| 辞書 | あらかじめ用意した翻訳。ボタン、エラー、画面名 |
| 有効言語 | 初期集合に入り、設問を公開できる言語 |

## 5. 要求

| ID | 要求 | 状態 |
| --- | --- | --- |
| D12-R01 | 表示言語はアプリ内の辞書と、設問・お知らせの言語別の文で切り替える | 確定 |
| D12-R02 | 日本語は有効言語に含める | 確定 |
| D12-R03 | 氏名、会社名、現場の固有名詞、電話番号、測定値、区分コードは翻訳しない | 確定 |
| D12-R04 | 応急処置とセルフチェックは人手の訳を正とし、自動翻訳の文を正にしない | 確定 |
| D12-R05 | 訳が無い言語では、その設問とお知らせを出さない | 確定 |
| D12-R06 | 初期の言語の一覧は未決とする。候補は英語、インドネシア語、ベトナム語、中国語 | 未決 |
| D12-R07 | 管理画面を作業者と同じく切り替えるかは未決とする。仮は管理画面を日本語のみとする | 仮 |

## 6. 仕様

| コード | 呼び方 | 状態 |
| --- | --- | --- |
| ja | 日本語 | 含める（D12-R02） |
| en | 英語 | Q.12.01 |
| id | インドネシア語 | Q.12.01。現行フォームに実例がある |
| vi | ベトナム語 | Q.12.01 |
| zh-CN | 中国語 | Q.12.01 |

| 対象 | 置き場所 |
| --- | --- |
| ボタン、エラー、画面名 | 辞書 |
| 設問文 | D07 の言語別 text |
| C-AID、C-SELF | 人手の訳（D12-R04） |
| お知らせ | D13 の言語別本文 |

初期の表示は、保存された選択、無ければブラウザの言語、無ければ ja。言語を変えても入力途中の値は残す（部品は D06）。

自由文の翻訳APIは今回の必須にしない（D02）。

## 7. 他領域との受け渡し

有効言語の一覧を D07 の公開条件と D13 の表示条件へ渡す。D06 はヘッダの切り替え部品だけを持つ。
