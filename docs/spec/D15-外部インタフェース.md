## 1. 目的

ブラウザ、API、電話、メールの境目で、何を渡すかを定義する。

## 2. 適用範囲

定義すること: 入口の名前と、その入口が運ぶ役割。

定義しないこと: 値の受理規則（D08）、判定（D09）、認証の意味（D10）、通知文の条件（D13）。

## 3. 参照

- D05 の構成
- D08 の伝送の形

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| 公開入口 | 作業者が現場トークンまたは個人トークンで使う入口 |
| 管理入口 | 管理者セッションが必要な入口 |

## 5. 要求

| ID | 要求 | 状態 |
| --- | --- | --- |
| D15-R01 | 作業者の送信には現場トークンが必要である | 確定 |
| D15-R02 | 回答の値は D08 の形で渡し、1つの項目に整数と yes を混ぜない | 確定 |
| D15-R03 | 個人情報の検証結果は、設問の値を含まずに返す | 確定 |
| D15-R04 | 画面のURLは出社用、休憩用、個人用、管理者ログインを分ける | 確定 |
| D15-R05 | form が欠けている、または arrival と break 以外の現場QRはエラーにする | 確定 |
| D15-R06 | 公開入口は連続送信を制限する | 確定 |
| D15-R07 | 管理入口は未認証を拒否し、権限外は存在を広く知らせない応答にする | 確定 |

## 6. 仕様

| 向き | 形 | 運ぶもの | 中身の定義 |
| --- | --- | --- | --- |
| ブラウザからAPI | 現場トークンでの参照 | 現場名、form、手入力の可否、公開設問、電話、言語 | D07、D10、D12、D14 |
| 同上 | 個人トークンでの参照 | 氏名、会社、現場、成否。設問値は含めない | D11 |
| 同上 | 回答の送信 | D08 の values。現場トークン必須 | D08 |
| 同上 | 管理者のログインとログアウト | セッション | D10 |
| 同上 | 回答の一覧と詳細 | D03 の範囲 | D03、D09 |
| 同上 | 対応状態の更新 | open / in_progress / done | D13 |
| 同上 | マスタの更新 | 権限で拒否する | D03 |
| ブラウザから電話 | tel | 現場の番号 | D14、D06 の W-09 |
| APIからメール | メッセージ | 通知 | D13 |
| 画面URL | `/s/{siteToken}?form=arrival` または `break`、`/i/{personToken}`、`/admin/login` | 入口（D15-R04、D15-R05） | D10、D11 |

## 7. 他領域との受け渡し

この文書は入口の名前と役割だけを持つ。拒否の条件は D16 の例外ID、値の検査は D08、見える範囲は D03 が定義する。

## 8. 未決事項

なし。チャットなど経路を足すかは Q.13.02（D13）。
