## 1. 目的

現場、組織、アカウント、回答の見出し、監査に何を持つかを定義する。

## 2. 適用範囲

定義すること: 台帳の名前と主な属性、監査に残す操作。

定義しないこと: 設問値の列（D08）、判定結果の列（D09）、個人トークンの検証規則（D11）。

## 3. 参照

- D03 のロール
- D02 の将来範囲（教育などは識別子を流用する）

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| 回答ヘッダ | 誰が、どの現場の、どのフォームを、いつ送ったかの行。設問の値は含まない |
| 監査 | 管理操作の記録。一覧を開いただけは含まない |

## 5. 要求

| ID | 要求 | 状態 |
| --- | --- | --- |
| D14-R01 | 協力会社、現場、管理者、作業者、回答ヘッダ、お知らせ、監査を台帳として持つ | 確定 |
| D14-R02 | 回答ヘッダの氏名と会社名は送信時点の文字列を保持し、後の改名で過去を書き換えない | 確定 |
| D14-R03 | 監査には、ログインの成否、抽出、詳細の初回表示、対応メモ、マスタ変更を残す | 確定 |
| D14-R04 | 今回、教育用の台帳は足さない。現場・会社・作業者の識別子は将来流用できる形にする | 確定 |
| D14-R05 | 健康情報の保管期間は未決とする | 未決 |

## 6. 仕様

| 台帳 | 主な属性 |
| --- | --- |
| organizations | 協力会社名 |
| sites | 表示名、緊急電話、有効、休憩間隔（分。60は仮）、手入力の許可 |
| site_tokens | 現場、form_type、秘密、失効 |
| admin_users | ログインID、パスワードの照合用の値、ロール、無効 |
| admin_sites | 管理者と現場 |
| workers | 会社、氏名、顔認証の外部ID（空可）、有効 |
| worker_site | 作業者と現場。未入力の母集団 |
| person_tokens | 作業者、現場、秘密、期限 |
| responses | 現場、作業者ID（空可）、form_type、氏名のコピー、会社名のコピー、送信時刻、出所（manual / person_token）、業務日 |
| notices | 対象現場、期間、言語別の本文 |
| audit_logs | 実行者、操作、対象、時刻 |

休憩間隔の60分は仮である。業務日の切り方は Q.16.01。

## 7. 他領域との受け渡し

ロール（D03）を admin_users に載せる。設問値（D08）と判定（D09）は responses にぶら下げるが、列の定義はそちらが持つ。外部IDは D11 が埋める。

## 8. 未決事項
