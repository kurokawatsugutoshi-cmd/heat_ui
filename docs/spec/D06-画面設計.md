## 1. 目的

必要な画面、画面遷移、各画面に置く部品を定義する。

## 2. 適用範囲

定義すること: 画面ID、遷移、部品、操作、その画面に載せる識別子。

定義しないこと: 設問の意味（D07）、値の型と範囲（D08）、色の意味（D09）、ログインの規則（D10）、言語の辞書（D12）。

## 3. 参照

- D03、D04
- `report-0924.pdf` の入力画面（出社時と休憩時のQR、セルフチェック、フローチャート、緊急連絡）

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| W-xx | 作業者の画面 |
| A-xx | 管理者の画面 |
| 部品 | ボタン、入力、表示。設問文そのものは部品に載る識別子で参照する |

## 6. 仕様

作業者ヘッダ: 言語、現場名、確定済みなら氏名。未確定なら氏名は出さない。

### 6.1 遷移（D06-R03、D06-R07）

```
現場QR → W-01 → W-03 → フォーム種別が決まっていれば W-05 または W-06
                         メニュー経由なら W-04
個人QR → 検証成功 → W-03（属性は表示済み）
         検証失敗 → 案内。手入力可なら W-03 の手入力（Q.11.02）

W-04 → W-05 W-06 W-07 W-08 W-09 W-11
W-05 と W-06 の下部 → W-07 W-08 W-09
送信成功 → W-10
W-08 → W-09
A-01 → A-02 を中心に A-03〜A-10
```

### 6.2 作業者画面（D06-R01、D06-R04〜R07、D06-R10）

| ID | 画面 | 部品 | 載せる識別子 | 置かないもの |
| --- | --- | --- | --- | --- |
| W-01 | QR着地 | 現場名、フォーム名、言語、続行、失敗理由、再試行 | 現場トークンの結果（D10） | 設問 |
| W-03 | 本人の確定 | 会社、氏名、「自分でない」、次へ | 属性（D10、D11） | 設問、顔撮影、血圧 |
| W-04 | メニュー | 6つの入口。出社済みの表示 | フォーム種別（D07） | 回答欄 |
| W-05 | 出社時チェック | 数値、区分、はい／いいえ、送信 | 出社時の `Q-*`。順は D07 の sort | 休憩時専用の設問 |
| W-06 | 休憩時報告 | はい／いいえ、送信。1画面 | 休憩時の `Q-*` | 血圧・脈拍・睡眠の部品 |
| W-07 | セルフチェック | 図と短文 | `C-SELF-01`〜`08` | 保存、判定 |
| W-08 | 応急処置 | 手順、電話への導線 | `C-AID` | 回答の保存 |
| W-09 | 緊急連絡 | 現場名、番号、発信 | 現場の電話（D14） | 設問 |
| W-10 | 送信完了 | 日時、種別、「終了」「続ける」 | 受付結果 | 他者の記録 |
| W-11 | お知らせ | 件名と本文 | D13 | 回答 |

W-03 の出し分け:

| 状態 | 部品 |
| --- | --- |
| 個人トークンが有効 | 氏名と会社は表示のみ。次へ |
| トークンが無く、手入力が許可 | 会社の選択、氏名、次へ |
| トークンが無効で手入力が不許可 | 理由と連絡。フォームへ進まない |
| すでに本人が確定している | 氏名の確認。「自分でない」で破棄 |

W-05 の並び: 現場名、会社と氏名（表示）、設問、セルフチェックへのリンク（送信の条件にしない）、送信。失敗時は入力を残す。二重送信を防ぐ。下部に W-08 と W-09。

W-06 の並び: 氏名と現場、休憩時の設問、W-08 と W-09、送信。

W-10: 共有端末では「終了（次の人へ）」を主ボタンにする。終了でセッションを消す。寿命は D10。警告の語を作業者へ出すかは未決。

### 6.3 管理者画面（D06-R02、D06-R08、D06-R09）

| ID | 画面 | 部品 |
| --- | --- | --- |
| A-01 | ログイン | ID、パスワード |
| A-02 | 一覧 | 日時、種別、会社、氏名、現場（本部のみ）、測定値、睡眠、はい／いいえ、判定、対応。フィルタは日付・現場・会社・判定・種別。行から A-03 |
| A-03 | 詳細 | 値、どの規則が効いたか、対応状態、メモ。メモは作業者画面へ出さない |
| A-04 | アラート／未入力 | 赤かつ未対応。未入力はマスタがある現場。休憩間隔の超過は推定である文 |
| A-05 | 現場・QR | 有効、表示名、協力会社、出社用と休憩用の再発行、印刷 |
| A-06 | 電話・閾値 | 所長は自現場の電話。本部は D09 の閾値と、黄を通知するかのスイッチ |
| A-07 | 設問管理 | D07 の文と極性、D12 の訳。値の保存形は編集しない |
| A-08 | アカウント | ロール、現場、協力会社、無効化、作業者、外部ID |
| A-09 | お知らせ | 言語別の件名と本文、対象現場、期間 |
| A-10 | 抽出 | 期間、現場、種別。権限内の一覧 |

A-02 の測定値は出社時だけ表示し、休憩時は空欄とする。更新間隔は仮に15秒。

## 7. 他領域との受け渡し

画面は識別子を並べる。`Q-*` は D07、値の部品の種類は D08 の値種別、判定の文字は D09、権限で隠す操作は D03。

## 8. 未決事項

| ID | 問い | 理由 |
| --- | --- | --- |
| Q.06.01 | 会社マスタが空の現場で、会社名の自由入力を出すか | マスタが空のときの運用が未定 |
| Q.06.02 | W-10 に「注意」「警告」を出すか | 診断の断定文は出さない。色の語だけ見せるかが未定 |
| Q.06.03 | W-09 の発信操作を記録するか | 誤操作も残る |
| Q.06.04 | A-02 の更新間隔 | 15秒は仮 |
| Q.06.05 | 閾値変更後に過去の色を描き直すか | 描き直さない場合、A-02 は保存時の D09 の結果を出す |
| Q.06.06 | A-10 に氏名を含めるか | 健康情報の出し方 |
