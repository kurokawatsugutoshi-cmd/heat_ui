## 1. 目的

受理済みの回答値から、通常・注意・警告のどれにするかを定義する。

## 2. 適用範囲

定義すること: レベルの名前、はい／いいえの読み方、測定値と区分の規則、結果の持ち方。

定義しないこと: 値の受理（D08）、設問の文言（D07）、画面の色の部品（D06）、通知先（D13）。

## 3. 参照

- `report-0924.pdf` の「黄：注意」「赤：警告」
- D07 の極性と悪い側の重さ
- D08 のスロット

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| normal | 通常。通知しない |
| caution | 注意。画面では黄 |
| alert | 警告。画面では赤 |
| 規則ID | 測定値または区分に対する1件の条件。例: SYS_HIGH |

## 5. 要求

| ID | 要求 | 状態 |

## 6. 仕様

入力は D08 が保存した値。出力は level と理由の列である（D09-R01、D09-R04）。

### 6.1 はい／いいえ（D09-R03）

D07 の極性と `severity_if_bad` を読む。

悪い側は、極性 positive かつ no、または極性 negative かつ yes。悪い側の設問が持つ重さの最大を、はい／いいえ分のレベルにする。

### 6.2 測定値と区分（D09-R06）

範囲外と比較不能な血圧は D08 が拒否する（D09-R05）。

| 規則ID | 読む code | 条件 | レベル | 状態 |
| --- | --- | --- | --- | --- |
| SYS_HIGH | Q-SYS | 160以上 | alert | 仮 |
| SYS_CAUTION | Q-SYS | 140〜159 | caution | 仮 |
| DIA_HIGH | Q-DIA | 100以上 | alert | 仮 |
| DIA_CAUTION | Q-DIA | 90〜99 | caution | 仮 |
| HR_HIGH | Q-HR | 120〜139 | caution | 仮 |
| HR_VERY_HIGH | Q-HR | 140以上 | alert | 仮 |
| SLEEP_SHORT | Q-SLEEP | h5。lt5 を採用した場合はそれも含む | caution | 仮 |

総合は、はい／いいえ分と上表のレベルの最大である（D09-R02）。

### 6.3 結果

| 項目 | 内容 |
| --- | --- |
| response_id | 回答 |
| level | normal / caution / alert |
| reasons | 規則IDまたは設問コードと、そのレベル |

理由は A-03 が読む。作業者へ語を出すかは Q.06.02。閾値は本部が変える。変えたあと既に保存した結果を描き直すかは Q.06.05。描き直さないときの既定は、新しい回答から新しい閾値を使うことである。

## 7. 他領域との受け渡し

受け取るもの: 受理済みスロット（D08）、極性と重さ（D07）。

渡すもの: level と reasons。D13 は alert を通知条件に使う。D06 はレベルの表示名を出す。
