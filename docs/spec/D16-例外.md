## 1. 目的

決めた規則から外れたときの振る舞いを、IDで一覧にする。

## 2. 適用範囲

定義すること: 例外ID、条件、振る舞い、規則の定義先。

定義しないこと: 新しい業務規則。規則そのものは各領域が持ち、この文書は外れたときの結果を指す。

## 3. 参照

- D06、D07、D08、D10、D11、D12、D13、D14、D15

## 4. 用語

| 用語 | 意味 |
| --- | --- |
| 例外ID | E- で始まる番号。振る舞いの参照に使う |

## 5. 要求

| ID | 要求 | 状態 |
| --- | --- | --- |
| D16-R01 | 例外はIDを持ち、条件と振る舞いと、規則を定義している領域を指す | 確定 |
| D16-R02 | 保存に失敗した入力は、成功したように見せない | 確定 |
| D16-R03 | 夜勤の業務日の区切りは未決とする | 未決 |
| D16-R04 | 管理者が測定値を画面から書き換える訂正は、未決が要るまで作らない | 未決 |

## 7. 他領域との受け渡し

各領域は、自分の要求が外れたときの結果をこの表のIDで参照する。振る舞いを変えるときは、先にこの表を直す。
